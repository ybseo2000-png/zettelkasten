# 결 · 지식의 정원

메모 하나가 그래프의 점이 되는 Git 기반 개인 지식 사이트입니다. 제목·본문에서 키워드를 추출하고, 공통 키워드가 있는 메모를 연결해 가까이 배치합니다. 글·이미지 작성, 검색, 그래프 확대, 목록 및 관련 메모 탐색을 지원합니다.

## 실행

Node.js 22 이상에서 `npm start`. 별도 패키지 설치나 데이터베이스가 필요 없습니다. `npm test`, `npm run build`로 검증하고 빌드합니다. `dist/`는 정적 배포 결과이며 `notes/*.json`이 원본입니다. 기본 로컬 서버는 127.0.0.1:3000입니다.

## GitHub Pages 게시

1. 이 프로젝트 파일을 `ybseo2000-png/zettelkasten` 저장소의 `main`에 커밋하고 푸시합니다.
2. GitHub 저장소 Settings → Pages → Source에서 GitHub Actions를 선택합니다.
3. 포함된 `.github/workflows/pages.yml`이 메모 검증·키워드 추출·정적 빌드·배포를 수행합니다. Actions 성공 후 Pages의 주소로 접속합니다.

코드나 메모를 푸시하거나 실제 공개 배포하는 작업은 아직 실행하지 않았습니다. 프로젝트 하위 경로에서도 작동하도록 상대 경로를 사용합니다.

## 웹에서 메모 추가

- **직접 저장:** 웹의 ‘GitHub 연결’에서 저장소와 브랜치를 설정하고, 해당 저장소만 대상으로 하는 Fine-grained personal access token을 입력합니다. Contents: Read and write 권한이 필요합니다. 토큰은 현재 탭의 메모리에만 보관하며 저장소·브라우저 저장소에는 쓰지 않습니다. 로그인 OAuth 흐름 대신 GitHub 토큰을 사용하는 첫 버전입니다. 토큰은 채팅에 제공하지 마세요.
- ‘새로운 메모’에서 제목, 글 또는 PNG/JPEG/WebP 이미지(최대 5MB)를 입력하고 저장합니다. GitHub Contents API로 `notes/<id>.json` 파일을 생성합니다. GitHub에 커밋되면 Pages가 다시 빌드됩니다. 조직 정책/브랜치 보호가 있으면 직접 저장이 제한될 수 있습니다.
- **토큰 없이:** 같은 화면에서 ‘메모 파일 내려받기’를 누르고 안내 링크의 GitHub `notes/` 폴더에 파일을 업로드한 뒤 Commit changes를 누릅니다. 인증은 GitHub에서 처리합니다.
- 이 대화에서 메모를 전달하면 같은 파일 형식으로 준비할 수 있습니다.

이미지는 메모 JSON에 포함되어 Git에 함께 보관됩니다. 이미지를 많이 쌓으면 저장소와 초기 로딩이 커질 수 있으므로 향후 별도 이미지 파일 및 지연 로딩으로 확장할 수 있습니다. 이미지 OCR·의미 기반 AI 추출은 없으며 키워드는 제목과 설명에서 규칙 기반으로 추출합니다.

## 보관과 공개 범위

메모를 삭제해도 Git 이력에 남습니다. 공개 저장소와 Pages에는 민감한 업무 자료를 올리지 마세요. GitHub 계정/저장소 권한이 쓰기 접근을 관리하며 사이트를 보는 데에는 로그인이 필요 없습니다. 예전 로컬 MVP의 `data/notes.json`은 자동 게시하지 않습니다. 기존 메모가 있으면 개별 `notes/*.json`으로 명시적으로 옮겨야 합니다.

`npm test`는 한국어 키워드 처리, 정적 사이트 빌드·재빌드, 잘못된 메모 거부를 검증합니다. GitHub API 권한과 실제 Pages 배포는 저장소 설정 후 별도로 확인해야 합니다.
