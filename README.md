# 결 · 지식의 정원

메모 하나가 그래프의 점이 되는 Git 기반 개인 지식 사이트입니다. 제목·본문에서 키워드를 추출하고, 공통 키워드가 있는 메모를 연결해 가까이 배치합니다. 글·이미지 메모 열람, 검색, 그래프 확대, 목록 및 관련 메모 탐색을 지원합니다.

## 실행

Node.js 22 이상에서 `npm start`. 별도 패키지 설치나 데이터베이스가 필요 없습니다. `npm test`, `npm run build`로 검증하고 빌드합니다. `dist/`는 정적 배포 결과이며 `notes/*.json`이 원본입니다. 기본 로컬 서버는 127.0.0.1:3000입니다.

## GitHub Pages 게시

1. 이 프로젝트 파일을 `ybseo2000-png/zettelkasten` 저장소의 `main`에 커밋하고 푸시합니다.
2. GitHub 저장소 Settings → Pages → Source에서 GitHub Actions를 선택합니다.
3. 포함된 `.github/workflows/pages.yml`이 메모 검증·키워드 추출·정적 빌드·배포를 수행합니다. Actions 성공 후 Pages의 주소로 접속합니다.

사이트 코드는 GitHub main에 반영되어 있습니다. 실제 공개 상태는 Pages 배포 성공 후 확인해야 합니다. 프로젝트 하위 경로에서도 작동하도록 상대 경로를 사용합니다.

## 메모 추가

웹사이트는 읽기 전용입니다. 로그인, 토큰 입력, 웹 작성 기능은 없습니다. 이 대화에서 메모를 전달하거나 저장소에 `notes/<고유 ID>.json` 파일을 추가하고 main에 반영하면, 다음 배포에서 키워드와 그래프가 갱신됩니다.

```json
{
  "id": "memo-001",
  "title": "발견한 사실",
  "text": "메모 본문",
  "image": "",
  "createdAt": "2026-10-28T00:00:00Z"
}
```

`image`는 선택 사항이며 PNG/JPEG/WebP의 base64 data URL을 지원합니다. 글 없이 이미지만 넣어도 되지만 제목은 필요합니다. 키워드는 빌드 시 제목과 본문에서 자동 추출합니다.

이미지는 메모 JSON에 포함되어 Git에 함께 보관됩니다. 이미지를 많이 쌓으면 저장소와 초기 로딩이 커질 수 있으므로 향후 별도 이미지 파일 및 지연 로딩으로 확장할 수 있습니다. 이미지 OCR·의미 기반 AI 추출은 없으며 키워드는 제목과 설명에서 규칙 기반으로 추출합니다.

## 보관과 공개 범위

메모를 삭제해도 Git 이력에 남습니다. 공개 저장소와 Pages에는 민감한 업무 자료를 올리지 마세요. GitHub 계정/저장소 권한이 쓰기 접근을 관리하며 사이트를 보는 데에는 로그인이 필요 없습니다. 예전 로컬 MVP의 `data/notes.json`은 자동 게시하지 않습니다. 기존 메모가 있으면 개별 `notes/*.json`으로 명시적으로 옮겨야 합니다.

`npm test`는 한국어 키워드 처리, 정적 사이트 빌드·재빌드, 잘못된 메모 거부를 검증합니다. 실제 Pages 배포는 저장소 설정 후 별도로 확인해야 합니다.

## PDF 문서 노드

PDF 기반 요약 메모 9개는 원본 PDF를 보여주는 문서 노드 하나로 대체했습니다. 직접 전달한 기존 국토계획평가 메모와 절차 순서도는 유지됩니다. 문서 노트 JSON에 `document: {"path":"documents/land-assessment-guide-2021.pdf","title":"2021년 국토계획평가제도 설명회.pdf"}`를 지정하고 원본 파일을 `public/documents/`에 보관합니다. 빌드 시 문서 경로·파일 존재·PDF 헤더를 확인합니다. 상세 창에서 PDF를 임베딩하며 새 탭 열기도 제공합니다. 모바일 표시 방식은 브라우저의 PDF 지원에 따라 다릅니다. 사이트 검색은 문서 제목·소개·키워드를 대상으로 하며 PDF 내부 검색은 PDF 뷰어에서 수행합니다.

모든 메모의 키워드는 최대 5개입니다. 자동 추출도 5개로 제한하며, 직접 지정한 키워드가 5개를 넘으면 빌드가 실패합니다.
